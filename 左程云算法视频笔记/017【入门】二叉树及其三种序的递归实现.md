```java
//中左右，左中右，左右中

//先序递归版
public static void preOrder(TreeNode head){
    if(head==null) return;
    System.out.println(head.val+" ");
    preOrder(head.left);
    preOrder(head.right);
}

//中序递归版
public  static void inOrder(TreeNode head){
    if(head==null) return;
    inOrder(head.left);
    System.out.println(head.val+" ");
    inOrder(head.right);
}

//后序递归版
public static void postOrder(TreeNode head){
    if(head==null) return;
    postOrder(head.left);
    postOrder(head.right);
    System.out.println(head.val+" ");
}
```
任何一个非空节点，在递归中都会调用三次
