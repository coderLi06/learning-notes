# 归并排序

1. 左部分有序，右部分有序，再利用merge让整体有序  

   1. 从中间分开，依次递归；

   2. 准备两个指针，一个辅助数组具有相同下标；

   3. 比较左右指针值大小，小的先放在辅助数组里（为了稳定性先放左边），随后指针右移；
   4. 最后将原数组内的值刷新成辅助数组中对应下标的值

2. 代码

   1. 递归版：  

   ```java
   public static int[] sortArray(int[] nums) {
    if(nnums.length > 1){
        mergeSort1(0, nums.length - 1);
    }
   }
   public static int MAXN = 50001;
   public static int[] arr = new int[MAXN];
   public static int[] help = new int[MAXN];
   public static int n;
   
   public static void mergeSort1(int l, int r){
       if(l == r) return;
       int m = (l + r) / 2;
       mergeSort1(l, m);
       mergeSort1(m + 1, r);
       merge(l, m, r);
   }
   
    public static void merge(int l, int m, int r){
       int i = l;//辅助数组开始下标
       int a = l;//左侧
       int b = m + 1;//右侧
       while(a <= m && b <= r){
           help[i++] = arr[a] <= arr[b] ? arr[a++] : arr[b++];
       }
       //处理一侧越界后剩下的部分
       while(a <= m){
           help[i++] = arr[a++];
       }
       while(b <= r){
           help[i++] = arr[b++];
       }
       //刷新原数组
       for(i = l; i <= r; i++){
           arr[i] = help[i];
       }
   }
   ```

   2. 非递归版：

      ```java
      public static void mergeSort2(){
          for(int l, m, r, step = 1; step < n; step <<= 1){
              l = 0;
              while(l < n){
                  m = l + step - 1;
                  if(m + 1 >= n) break;//没有右侧，不merge
                  r = Math.min(l + (step << 1) - 1, n - 1);
                  merge(l, m, r);
                  l = r + 1;
              }
          }
      }
      ```
