一个单向链表一般需要两个变量维护，头head，尾cur

```java
//力扣
public static ListNode partition(ListNode head, int x){
    ListNode lHead = null, lTail = null;
    ListNode rHead = null, rTail = null;
    ListNode next = null;
    while(head != null){
        next = head.next;
        head.next = null;
        if(head.val < x){
            if(lHead == null){
                lHead = head;
            }else{
                lTail.next = head;
            }
            lTail = head;
        }
        if(head.val >= x){
            if(rHead == null){
                rHead = head;
            }else{
                rTail.next = head;
            }
            rTail = head;
        }
        head = next;
    }
    if(lHead == null) return rHead;
    lTail.next = rHead;
    return lHead;
}

/*
注意；   next = head.next;
        head.next = null;
        先把head.next设为空再赋值给小链表
        如果直接赋head，大链表的连接关系会存在于小链表中，
        1 -> 4 -> 3 -> 2 -> 5 -> 2   x = 3
        1 2 2
        4 3 5最后一个元素指向的是大链表最后一个2
        连接时会出现1 -> 2 -> 2 <-> 4 -> 3 -> 5
        且原链表连接关系存在于小链表中
*/
```
