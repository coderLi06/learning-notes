# 哈希表、有序表和比较器的用法

## 哈希表

时间复杂度O(1) 大常数

```java
//map比set多一个伴随数据
String str1 = new String("hello");
String str2 = new String("hello");
//这里一二是不同的内存地址
//Integer,Long,Double, Float,
//Byte,Short,Character,Boolean,String都有此特征
//==比较int这种小数据时比较值，比较String时就是内存地址
//str1 == str2返回false
//.equals()比较的是值，这里返回true

HashSet<String> set = new HashSet<>();
set.add(str1);
System.out.println(set.contains("hello"));//返回true
//下面也返回true，因为HashSet会根据值查找
System.out.println(set.contains(str2));
set.add(str2);
//下面是1，因为两个变量是同一个值，上面的变量类型都是如此
System.out.println(set.size());
set.remove(str1);//remove会清理掉值hello，set里没有值
set.clear();

HashMap<String, String> map1 = new HashMap<>();
map1.put(str1, "World");
```

## 有序表

`TreeMap`底层是红黑树

会把key按照顺序排好  时间复杂度O(log(n))

会去重

```java
TreeMap<Integer, String> tm = new TreeMap<>();
tm.put(5, "这是5");
tm.put(7, "这是7");
System.out.println(tm.containsKey(5));
System.out.println(tm.firstKey());//最小的key
System.out.println(tm.lastKey());//最大的key
//所有key中<=4且最近的key
System.out.println(tm.floorKey(4));
//所有key中>=4且最近的key
System.out.println(tm.ceilingKey(4)); 

TreeSet<Integer> set = new TreeSet<>();
System.out.println(set.polllast()); //从大到小弹出
```

## 比较器

```java
public Employee(int c, int a){
    company = c;
    age = a;
}

public static class EmployeeComparator implements Comparator<Employee>{
    @Override
    public int compare(Employee o1, Employee o2){
        //谁年龄小优先级更高
        if(o1.age < o2.age) return -1;
        else if(o1.age > o2.age) return 1;
        else return 0;
    }
    /*
    任何比较器都默认
    返回负数o1优先级高，正数o2高
    不再有大小概念，而是优先级
    */
}
```
