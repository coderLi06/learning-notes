## 问题：无序数组中求第k大的数（常考内容）
运用荷兰国旗问题的思路，如果==x区间命中k下标返回，
反之在左右两侧选一侧继续寻找（与快速排序的区别）
时间复杂度O(n)，额外空间复杂度O(1)
还有一个BRPRT算法可以不用随机，
依然做到时间复杂度O(n)，空间O(logn)（冷）
```java
public static int first, last;
public static intrandomizedSelect(int[] arr, int i){
    int ans = 0;//这个找到的是第i小的数
    for(int l = 0, r = arr.length-1; l<=r){
        partition2(arr,l,r,arr[l+(int)Math.random()*(r-l+1)]);
        if(i<first) r = first -1;
        else if(l>last) l = last+1;
        else{
            ans = arr[i];
            break;
        }
    }
    return ans;
}

public static void partition2(int[] arr,int l, int r, int x){
    first = l, last = r;
    int i = l;
    while(i<=last){
        if(arr[i] == x) i++;
        else if(arr[i] < x) swap(arr,first++, i++);
        else swap(arr,i, last--);//注意如果>x时i不++，
        // 还要再次比较从last换过来的数
    }
}

public static void swap(int[] arr, int a, int b){
    int tmp = arr[a];
    arr[a] = arr[b];
    arr[b] = tmp;
}
```
