## ACM风格

1. 推荐使用`BufferReader`读取数据，每次从文件中读取一块内容到内存，

     `Scanner`每次读取一行数据，效率低

   `BufferedReader br = new BufferedReader(new InputStreamReader(System.in));`

2. `StreamTokenizer` 能高效地一个个提取数字

   `StreamTokenizer in = new StreamTokenizer(br);`

3. 判断文件有没有结束

   ```java
   //提交答案使用，也是内存托管区
   printWriter out = new PrintWriter(new OutputStreamWriter(System.out));
   while(in.nextToken() != StreamTokenizer.TT_EOF){
       int n = (int)in.nval;//第一个数据转成数字
       in.nextToken();//读取第二个数字
       int m = (int)in.nval;
       int[][] mat = new int[n][m];
       for(int i = 0; i < n; i++){
           for(int j = 0; j < m; j++){
               in.nextToken();
               mat[i][j] = (int)in.nval;
           }
       }
       out.println(maxSumSubmatrix(mat, n, m));
   }
   out.flush();
   out.close();
   ```

4. 推荐使用全局静态变量，节约空间

   ```java
   //ACM风格测试会计算累积使用空间，同一块内存多次复用会计算多次
   public static int MAXN = 201;
   public static int MAXM = 201;
   public static int[][] mat = new int[MAXN][MAXM];
   ```

   

5. 按行读取

   ```java
   public static String line;
   public static String[] parts;
   public static int sum;
   BufferReader in = new BufferReader(new InputStreamReader(System.in));
   PrintWriter out = new PrintWriter(new OutPutStreamWriter(System.out));
   while((line = in.readLine()) != null){
       parts = line.split(" ");
       sum = 0;
       for(String num : parts){
           sum += Integer.valueOf(num);
       }
       out.println(sum);
   }
   out.flush();
   in.close();
   out.close();
   ```
