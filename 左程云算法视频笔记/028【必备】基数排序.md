# 基数排序

 

1. 基于比较的排序：只需要定义两个对象间的比较行为，比较通用
2. 不基于比较的排序：对数据特征有要求，不通用

3. 本段代码可以排序任意一组相同进制的非负数

   如果有负数，找到最小值，每个数减去它得正数，排好序加回来

   ```java
   //BASE表示多少进制，目前默认10进制
   public static int BASE = 10;
   public static int MAXN = 50001;
   public static int[] help = new int[MAXN];
   //在每次遍历时，相应位置存放此次遍历位数为对应值的总个数，词频统计
   public static int[] cnts = new int[BASE];
   //bits表示当前进制下最大数的位数，n数组长度
   public static void radixSort(int[] arr, int n, int bits){
       //offset用来辅助求各位数
       for(int offset = 1; bits > 0; offset *= BASE,bits--){
           Arrays.fill(cnts, 0);
           //数字从右往左依次提取位数技巧
           for(int i = 0; i < n; i++){
               cnts[(arr[i]/offset)%BASE]++;
           }
           //统计某一位上小于某个数的值出现的次数
           for(int i = 1; i < BASE; i++){
               cnts[i] = cnts[i] + cnts[i-1];
           }
           //按照出现的次数确定放到help对应下标上
           for(int i = n-1; i >= 0; i--){
               help[--cnts[(arr[i] / offset) % BASE]]= arr[i];
           }
           for(int i = 0; i < n; i++){
               arr[i] = help[i];
           }
       }
   }
   
   //返回number在BASE进制下有几位
   ppublic static int bits(int number){
       int ans = 0;
       while(number > 0){
           ans++;
           number /= BASE;
       }
       return ans;
   }
   ```
