# 欧几里得算法

1. 适用：求两个数的最大公约数

2. 数学原理：

   设d = gcd(a, b)

   - a = m·d，b = n·d（m,n互质）
   - 设 a = q·b + r（0 ≤ r < b）
   - 则 r = a - q·b = m·d - q·n·d = (m - q·n)·d
   - 所以 d 也是 b 和 r 的公约数
   - 反过来，b 和 r 的任何公约数也是 a 的约数
   - 因此 gcd(a,b) = gcd(b,r)

3. 代码示例：

   ```cpp
   int gcd(int a, int b) {
       while (b) {          // 当 b ≠ 0 时继续
           int temp = b;    // 1. 保存当前的 b
           b = a % b;       // 2. 计算新的余数
           a = temp;        // 3. 原来的 b 成为新的 a
       }
       return a;            // 当 b=0 时，a 就是最大公约数
   }
   ```
