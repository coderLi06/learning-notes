# 堆结构

## 完全二叉树

1. 定义：一层满了再起下一层，永远从左往右
2. n个节点，树的层数：`log2(N)`向上取整
3. 节点i的父节点：(i-1) / 2（向下取整）
4. 节点i的左孩子：2 * i + 1; 节点i的右孩子：2 * i +2

## 大根堆

1. 任意子树内的最大值一定在顶部

2. i位置的数，向上调整大根堆代码:   

   `public static void heapInsert(int[] arr, int i){`

   ​	`while (arr[i] > arr[(i-1) / 2]){`

   ​	`	swap(arr, i, (i - 1) / 2);`	

   ​	`	i = (i - 1) / 2;`

   ​	`}`

   `}`

3. i位置的数变小，想维持大根堆结构，需要向下调整大根堆，当前堆大小为size  

   代码：

   ``` java
   //用数组中的数据创建堆结构
   public static void heapify(int[] arr, int i, int size){
   	int l = i * 2 + 1;//如果根节点为0就是i*2
       while(l < size){
           //评选最强孩子的下标
           int best = l + 1 < size && arr[l + 1] > arr[l] ? l + 1 : l;
           //评选最强下标（孩子和自己之间）
           best = arr[best] > arr[i] ? best : i;
           //如果最强下标是自己，说明已经调整完成
           if(best == i) break;
           swap(arr, best, i);//交换值
           l = i * 2 + 1;//继续向下调整
       }
   }
   ```

   

## 堆排序

```java
//从顶到底建立大根堆，O(n * log(n))
//依次弹出堆内最大值并排好序，O(n * log(n))
//整体时间复杂度O(n * log(n))
public static void heapSort1(int[] arr){
    int n = arr.length;
    //建堆
    for(int i = 0; i < n; i++){
        heapInsert(arr, i);
    }
    //排序
    int size = n;
    while(size > 1){
        swap(arr, 0, --size);
        heapify(arr, 0, size);
    }
}
//从底到顶建堆就是从最底部依次确认每个子堆为大根堆
//有n/2个需要往下看一层，n/4个往下看两层
//复杂度计算：n/2 + n/4*2 + n/8*3 + ...
//复杂度：O(N)
public static void heapSort2(int[] arr){
    int n = arr.length;
    for(int i = n-1; i >= 0; i--){
        heapify(arr, i, n);
    }
    int size = n;
    while(size > 1){
        swap(arr, 0, --size);
        heapify(arr, 0, size);
    }
}
/*复杂度差异原因分析：
从顶到底建堆时，上面节点少，看的层数少，下面节点多，
但需要往上看并调整的层数多
而从底到顶建堆，下面节点多反而看的层数少

整个的时间复杂度：O(nlog(n))
空间复杂度：O(1) （因为以最初的数组为处理空间）
*/
```
