# 递归和master公式

## 递归

1. 递归底层是利用系统栈实现的，比内存栈更加昂贵
2. 任何递归函数都可以改成非递归，自己压栈，用内存空间
3. 工程中几乎一定要改成非递归
4. 多画递归调用图

## master公式

1. 所有子问题规模相同的递归才能用master公式

   T(n) = a * T(n/b) + O(n^c)

   a是几次，b是分成几份，c是其他部分是n的几次方

2. 结论
   1. log(b,a) < c, 复杂度为O(n^c) (n的c次方)
   2. 大于， O(n^log(b,a))
   3. 等于，O(n^c * log(n))  

3. 补充

   T(n) = 2 * T(n/2) + O(n*log(n))

   复杂度为O(n * log(n) * log(n))
