# 📘 约瑟夫环完全掌握笔记

## 一、问题定义
**约瑟夫环问题**（Josephus Problem）：n个人围成一圈，从第1个人开始报数，每次数到第m个人就将其淘汰，然后从下一个人重新开始报数，直到剩下最后一个人，求这个人的初始编号。

## 二、核心递推公式

### 🧮 公式推导
**0-based编号**（编号0到n-1）：
```
f(1, m) = 0                            # 只有1个人时，幸存者编号为0
f(n, m) = (f(n-1, m) + m) % n          # n > 1时
```

**1-based编号**（编号1到n）：
```
result = f(n, m) + 1
```

### 🔑 递推理解
1. **第一轮淘汰**：淘汰编号为 `(m-1) % n` 的人
2. **重新编号**：删除后，剩下的人重新编号为0到n-2
3. **新旧映射**：新编号 → 旧编号 = (新编号 + m) % n
4. **递归关系**：f(n,m) = (f(n-1,m) + m) % n

### 💻 代码实现
```cpp
// 非递推版本（最优）
int josephus(int n, int m) {
    int res = 0;  // f(1,m)=0
    for (int i = 2; i <= n; i++) {
        res = (res + m) % i;
    }
    return res + 1;  // 转换为1-based
}

// 递归版本
int josephus_recursive(int n, int m) {
    if (n == 1) return 0;
    return (josephus_recursive(n-1, m) + m) % n;
}
```

```cpp
// 数组模拟
int josephus_array(int n, int m) {
    vector<bool> alive(n, true);
    int idx = 0, count = n;
    while (count > 1) {
        int step = 0;
        while (step < m) {
            if (alive[idx]) step++;
            if (step < m) idx = (idx + 1) % n;
        }
        alive[idx] = false;
        count--;
    }
    for (int i = 0; i < n; i++) if (alive[i]) return i + 1;
    return -1;
}
```

## 四、特殊情形与优化

### 1. **m=2时的快速解法**
当m=2时，有O(log n)解法：
```
设 n = 2^a + l （0 ≤ l < 2^a）
则幸存者编号 = 2*l + 1
```

代码实现：
```cpp
int josephus_m2(int n) {
    int highest_bit = 1;
    while (highest_bit * 2 <= n) highest_bit *= 2;
    int l = n - highest_bit;
    return 2 * l + 1;
}
```

**验证**：n=41 → 二进制101001 → l=9 → 结果=19

### 2. **m=1的情况**
当m=1时，直接淘汰报数的人：
```
幸存者编号 = n  （最后剩下的人）
```

### 3. **大n优化**
当n非常大时（如n>10⁷），可以分段计算：
```cpp
int josephus_large_n(long long n, int m) {
    if (m == 1) return n;
    long long res = 0, i = 2;
    while (i <= n) {
        long long step = (i - res + m - 2) / (m - 1);
        if (step > n - i + 1) step = n - i + 1;
        res = (res + m * step) % (i + step - 1);
        i += step;
    }
    return res + 1;
}
```

## 五、常见变种问题

### 变种1：求第k个被淘汰的人
```cpp
int kth_eliminated(int n, int m, int k) {
    vector<bool> alive(n, true);
    int idx = 0, eliminated = 0;
    while (eliminated < k) {
        int step = 0;
        while (step < m) {
            if (alive[idx]) step++;
            if (step < m) idx = (idx + 1) % n;
        }
        alive[idx] = false;
        eliminated++;
        if (eliminated == k) return idx + 1;
    }
    return -1;
}
```

### 变种2：反向约瑟夫
已知n和幸存者编号x，求可能的m值（可能有多个解）：
```cpp
vector<int> find_m_values(int n, int survivor) {
    vector<int> result;
    for (int m = 1; m <= n * 2; m++) {
        if (josephus(n, m) == survivor) {
            result.push_back(m);
        }
    }
    return result;
}
```

### 变种3：m值变化的情况
第i轮淘汰第(m+i)个人：
```cpp
int josephus_variable_m(int n, int base_m) {
    int res = 0;
    for (int i = 2; i <= n; i++) {
        int m = base_m + (n - i);  // 每轮m增加1
        res = (res + m) % i;
    }
    return res + 1;
}
```

## 六、重要性质与规律

### 数学性质
1. **对称性**：f(n, m)与n、m的奇偶性相关
2. **周期性**：当m固定时，f(n,m)随n增长呈现规律
3. **二进制规律**：m=2时，幸存者编号等于n的二进制循环左移一位

### 时间复杂度对比
| 输入规模       | 推荐算法   | 原因             |
| -------------- | ---------- | ---------------- |
| n ≤ 10⁶        | 递推公式   | O(n)足够快       |
| n ≤ 100        | 模拟法     | 代码直观，易调试 |
| n > 10⁷, m较小 | 分段计算   | 避免O(n)循环     |
| m=2            | 二进制解法 | O(log n)最优     |

## 八、易错点与注意事项

### ❌ 常见错误
1. **编号混淆**：忘记0-based和1-based转换
2. **取模错误**：写错取模的除数（应该是%n不是%(n-1)）
3. **边界处理**：n=1或m=1的特殊情况
4. **效率问题**：对大数据使用模拟法导致超时

### ✅ 正确做法
```cpp
// 正确模板
int josephus(int n, int m) {
    int res = 0;                    // f(1,m)=0
    for (int i = 2; i <= n; i++) { // 从2到n递推
        res = (res + m) % i;        // 关键公式
    }
    return res + 1;                 // 转1-based
}
```

## 十、总结与技巧

### 🎯 核心掌握点
1. **递推公式**：f(n,m) = (f(n-1,m) + m) % n
2. **边界条件**：f(1,m) = 0
3. **编号转换**：结果+1得1-based编号

### 💡 记忆口诀
> “一人为零，递推加模；  
> 规模减一，编号重排；  
> 旧号新号，差m映射；  
> 循环递推，幸存可得。”

### 🚀 快速解题步骤

4. 输出时转换为1-based编号
