## 078合并k个升序链表
方法1：准备一个容器，把所有节点放入使用比较器
时间：O(nlogn)  空间：O(n)
方法2：准备一个小根堆，放入链表头结点
时间：O(nlogk)  空间：O(k)

```java
public static ListNode mergeKList(ArrayList<ListNode> arr){
    //小根堆
    PriorityQueue<ListNode> heap = new PriorityQueue<>((a,b) -> a.val-b.val);
    for(ListNode h: arr){
        if(h != null) heap.add(h);
    }
    if(heap.isEmpty()) return null;
    //先弹出一个节点作为头部，一个变量作为链表末尾
    ListNode h = heap.poll();
    ListNode pre = h;
    if(pre.next != null){
        heap.add(pre.next);
    }
    while(!heap.isEmpty()){
        ListNode cur = heap.poll();
        pre.next = cur;
        pre = pre.next;
        if(cur.next != null){
            heap.add(cur.next);
        }
    }
    return h;
}
```
